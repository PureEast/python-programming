Student Record Management System - Bug Report
Original file: student_records.py

Bug #: 1
Type: Crash
Line(s): 67-69
Original:
        csv_file = open(csv_filename, newline="")
        csv_reader = csv.DictReader(csv_file)
        csv_file.close()
Fixed:
        with open(filename, "r", newline="", encoding="utf-8-sig") as csv_file:
            csv_reader = csv.DictReader(csv_file)
            # Iterate through csv_reader while the file is still open.
Symptom: Iterating over csv_reader after closing the file can raise ValueError: I/O operation on closed file.
Explanation: Keep the file open for the entire iteration, preferably with a with statement so it closes safely afterward.

Bug #: 2
Type: Logic
Line(s): 135-140
Original:
            while search_index <= len(student_records):
                if student_records[search_index]["StudentID"].upper() == search_id:
                    found_student = student_records[search_index]
                    search_index = len(student_records)  - 1      # Force loop to end
                else:
                    search_index = search_index + 1
Fixed:
            search_index = 0
            while search_index < len(student_records):
                if student_records[search_index]["StudentID"].strip().upper() == search_id:
                    found_student = student_records[search_index]
                    break
                search_index += 1
Symptom: The <= condition permits the index to reach len(student_records), which is outside the list and causes IndexError.
Explanation: Use < rather than <= so the index never reaches the list length; the loop's termination behaviour is separately corrected in Bug 10.

Bug #: 3
Type: Logic
Line(s): 86
Original:
            student_records.append(student_record)
Fixed:
        loaded_records = []
        # Append to this temporary list, then replace student_records after a successful load.
        loaded_records.append(student_record)
        student_records = loaded_records
Symptom: Loading the same CSV twice appends the same ten records again, resulting in 20 records.
Explanation: Build a fresh list during each load and replace the old collection only after the file has been read successfully.

Symptom: The listing loop does not increment row_number, so every row would display the same row number.
Explanation: enumerate(..., start=1) supplies a new sequential number for each student.

Bug #: 10
Type: Subtle
Line(s): 138-140
Original:
                    search_index = len(student_records)  - 1      # Force loop to end
                else:
                    search_index = search_index + 1
Fixed:
            for current_student in student_records:
                if current_student["StudentID"].strip().upper() == search_id.strip().upper():
                    return current_student
Symptom: Setting the index to len(student_records)-1 does not reliably terminate the loop; if the last record matches, the loop can repeatedly revisit that record indefinitely.
Explanation: Use an explicit return/break when a match is found rather than trying to force loop termination by assigning an index.
